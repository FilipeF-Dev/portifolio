# Portfólio

Página pessoal com meus projetos, como trabalho e minhas competências.

Next.js 16 · React 19 · TypeScript · Tailwind 4. Página única e estática.

## Rodando

```bash
npm install
npm run dev
```

## Onde mexer

Todo o texto está em [`src/content/dados.ts`](src/content/dados.ts): perfil,
projeto em destaque, projetos, método, competências e trajetória. Os
componentes em `src/components` só desenham.

Para trocar a foto, coloque o arquivo em `public/` e aponte `perfil.foto` para
ele. Sem foto, aparecem as iniciais.
